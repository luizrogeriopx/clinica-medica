# Clínica Médica – Site Institucional

Este repositório contém o site **Clínica Médica**, um projeto institucional desenvolvido para apresentar serviços médicos, especialidades, informações da clínica e canais de contato.  
O site foi construído com **HTML5, CSS3 e JavaScript**, priorizando clareza, credibilidade e boa experiência do usuário.

🔗 **Acesse o site online:**  
https://luizrogeriopx.github.io/clinica-medica/

---

## 🏥 Sobre o projeto

O site funciona como uma **vitrine digital profissional** para clínicas médicas, oferecendo:

- Apresentação institucional da clínica  
- Lista de especialidades e serviços médicos  
- Layout limpo, moderno e confiável  
- Seção de contato e informações essenciais  
- Navegação simples e objetiva  

Ideal para clínicas e profissionais da área da saúde que desejam fortalecer sua presença online.
